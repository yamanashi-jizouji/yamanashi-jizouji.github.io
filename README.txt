地蔵寺ホームページ Ver.1

1. index.html をブラウザで開くと確認できます。
2. 公開前に以下を差し替えてください。
   - 電話番号
   - メールアドレス（現在 example@example.com）
   - 葬儀・法要の具体的対応内容
   - 墓地の区画・費用・空き状況（掲載する場合）
   - 寺院の実写真
3. style.css で色・余白・文字サイズを変更できます。
4. Google Maps は住所検索の埋め込みを使用しています。

参考にした情報設計: https://bridge-sys.jp/yukaji/
デザイン・文章・コードは地蔵寺向けに新規作成しています。
